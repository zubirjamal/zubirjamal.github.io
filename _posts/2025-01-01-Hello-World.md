If you are reading this, you might be wondering: *"Why start a text blog when there are already videos?"*

### 💡 The "Copy-Paste" Problem
As much as I love making videos, I realized a major pain point for us tech enthusiasts: **trying to copy YAML code or configuration snippets from a YouTube video is challenging.** 

Saya nak kongsikan perkara yang sama dalam bentuk web. Kenapa? 
1. **Senang nak refer balik:** You can easily search, bookmark, and revisit these guides.
2. **Copy-paste friendly:** No more pausing the video every 2 seconds to type out a configuration file.
3. **Deeper technical context:** Some things are just easier to explain with structured text, code blocks, and diagrams than in a 10-minute video.

### 🚀 What’s Coming to `Zubir.tech`
This blog will serve as the official "companion" to my video content, but it will also feature exclusive deep dives. 

Moving forward, saya akan keluarkan beberapa **custom Home Assistant integration repositories**. Bermakna, tak perlu dah nak guna template atau workaround yang rumit macam sebelum ni. Everything will be streamlined and designed specifically for our local Malaysian context (hardware availability, Unifi networking quirks, and more).

I will also be releasing companion video walkthroughs for these new integrations, linking directly back to the code hosted here.
